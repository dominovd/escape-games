# Castle of Secrets: The Great Hall: walkthrough

1. Great hall: open Fireplace
2. Fireplace: Gauntlet → get Taper
3. Fireplace: Fire tools → get Poker
4. Fireplace: use Taper on Fire → get Lit taper
5. Fireplace: use Poker on Ashes → get Brass gear, Charred note
6. Go back to Great hall
7. Great hall: open Grandfather clock
8. Grandfather clock: use Brass gear on Clock face
9. Grandfather clock: Clock hands → solve "Clock hands" (answer: 7 15)
10. Grandfather clock: Pendulum → get Silver key
11. Go back to Great hall
12. Great hall: open Dining table
13. Dining table: use Silver key on Jewelry box → get Signet ring
14. Dining table: use Lit taper on Candelabra → solve "Candelabra" (answer: III I IV II)
15. Dining table: Folded letter → get Folded letter
16. Go back to Great hall
17. Great hall: open Portrait
18. Portrait: use Signet ring on Crest on the frame
19. Portrait: Wall safe → solve "Wall safe" (answer: 6139)
20. Portrait: Inside the safe → get Iron key
21. Go back to Great hall
22. Great hall: open Iron gate
23. Iron gate: use Iron key on Gate lock
24. Iron gate: Staircase
